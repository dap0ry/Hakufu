# Idiomas (español / inglés) — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development / executing-plans. Steps use `- [ ]`.

**Goal:** Hakufu entera en español o inglés, elegible en Ajustes, cambio al momento; publicar v0.11.0-beta.4.

**Architecture:** `I18n/Localizer` (singleton) carga `Assets/i18n/<area>.<lang>.json` (EmbeddedResource) y expone
`Get/Format/Culture/Observe/SetLanguage`; `{i18n:T key}` enlaza vistas a `Observe(key)`. Al cambiar idioma,
`NavigationService.Reload()` recrea la pantalla actual. Task 1 monta la base; Tasks 2–7 traducen cada área
en paralelo (archivos distintos); Task 8 integra, revisa en inglés y publica.

**Tech Stack:** .NET 10, Avalonia 11.3 (compiled bindings), xUnit + Avalonia.Headless.

**Spec:** `docs/superpowers/specs/2026-10-08-idiomas-design.md`

## Global Constraints

- Claves: `<area>.<algo>` en minúsculas con puntos (`settings.title`), `common.*` solo en `common.*.json` (Task 1).
- Cada área solo toca SUS vistas, SUS ViewModels/servicios y SUS `Assets/i18n/<area>.es.json` + `.en.json`.
  Si necesita una clave común nueva, la crea en su propio archivo con su prefijo (no toca `common`).
- Español: copiar el texto actual EXACTO (no reescribir). Inglés: natural, corto, mismo tono; UI en inglés de producto
  (sentence case: "Library", "Back up", "Reading now").
- Formatos con `{0}` (string.Format) y `L.Culture` para números/fechas. Nada de concatenar frases.
- Las vistas usan `xmlns:i18n="using:Hakufu.I18n"` y `Text="{i18n:T key}"`. Compiled bindings siguen activos.
- Tests: `dotnet test tests/Hakufu.Tests` siempre verde al acabar cada tarea (el test de textos a mano solo para las vistas del área).
- Commits locales (rama `feat/idiomas`); sin push hasta Task 8.
- Ejecutar dotnet con `export DOTNET_ROOT=~/.dotnet PATH=~/.dotnet:$PATH`.

## Review Focus

1. Cambiar de idioma en Ajustes con la barra de actualizaciones visible → la barra cambia de idioma también (Task 1 test).
2. Textos con número/fecha (perfil, «12 colecciones · 80 tomos», horas) bien formateados en inglés (Task 5/3 tests).
3. Instalación existente sin `Language` → sigue en español aunque el sistema esté en inglés (Task 1 test).
4. Textos ingleses más largos que no caben (botones, menú de Inicio con fuente grande) → capturas Task 8.
5. JSON de un idioma con una clave que falta → se ve la clave, nunca crash; el test de paridad lo impide.

### Task 1: Base de idiomas (Localizer, `{i18n:T}`, selector, recarga)

**Files:** Create `I18n/Localizer.cs`, `I18n/T.cs`, `Assets/i18n/common.es.json`, `Assets/i18n/common.en.json`,
`tests/Hakufu.Tests/I18nTests.cs`. Modify `Hakufu.csproj` (EmbeddedResource `Assets\i18n\*.json`),
`Data/AppDataStore.cs` (`Language`), `App.axaml.cs` (aplicar idioma al arrancar), `Services/NavigationService.cs`
(`Reload()`), `MVVM/ViewModel/SettingsViewModel.cs` + `MVVM/View/SettingsView.axaml` (selector Idioma),
`MVVM/ViewModel/UpdateBannerViewModel.cs` (refrescar en `LanguageChanged`), `CLAUDE.md`.

**Interfaces (Produces):**
```csharp
namespace Hakufu.I18n;
public sealed class Localizer {
  public static Localizer Instance { get; }
  public string Language { get; }                       // "es" | "en"
  public CultureInfo Culture { get; }                   // es-ES | en-US
  public string Get(string key);                        // falta → key
  public string Format(string key, params object?[] args); // string.Format(Culture, Get(key), args)
  public IObservable<string> Observe(string key);       // emite el valor actual y en cada cambio
  public void SetLanguage(string lang);                 // "es"/"en"; otro → "en"
  public event Action? LanguageChanged;
  public static string ResolveInitial(string saved, bool hasExistingData, CultureInfo system);
}
public static class L { Get, Format, Culture (atajos a Localizer.Instance) }
public sealed class T : MarkupExtension { public T(string key); public string Key; } // {i18n:T key}
```
`ResolveInitial`: guardado "es"/"en" → ese; vacío + datos existentes → "es"; vacío sin datos → sistema `es*` → "es", si no "en".
`hasExistingData` = `Mangas.Count>0 || LibraryRoot!="" || TotalUsageSeconds>0 || ReadingLog.Count>0`.

### Tasks 2–7: traducir cada área (en paralelo, cada una en su worktree)

Para su área: (a) mover TODO texto visible de sus `.axaml` a `{i18n:T <area>.…}`; (b) en sus ViewModels/servicios,
sustituir literales visibles por `L.Get/L.Format` y `CultureInfo` fija por `L.Culture`; (c) crear `<area>.es.json`
(texto actual exacto) y `<area>.en.json`; (d) añadir sus vistas a `TranslatedViews`; (e) un test de su área que cree
su ViewModel con `Localizer.Instance.SetLanguage("en")` y compruebe 2–3 textos en inglés (incluido uno con número/fecha
si su área los tiene) y vuelva a "es" al final; (f) suite verde; commit `HMR idiomas: <área> en inglés`.
