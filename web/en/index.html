Hakufu Manga Reader

The simplest, nicest and most useful offline manga reader. Sort your PDF, CBR and CBZ files into collections. No accounts, and free.

Download Hakufu See it in action

For Windows, macOS and Linux.

Your library

Pick a folder and Hakufu turns it into your bookshelf: every subfolder is a collection, with its covers stacked up and how far you have read.

All your collections

Open any collection to see all its volumes in order, with the page count of each. Sort them by name, by date or by hand.

Your reader profile

Hakufu keeps track of what you read without you lifting a finger. See your progress like in a fitness app, and share it.

  • Hours, pages and volumes finished, from day one
  • Your last 12 weeks in a chart, with your streak
  • Your favorite and what you are reading right now
  • Save it as an image, landscape or portrait

One page or two

Read page by page, or with the volume open like a real book. Hakufu remembers where you left off.

  • Zen mode in full screen, with nothing around
  • Pages flip as you turn them, or no animation if you prefer
  • Keyboard shortcuts you can change to your liking

How it was made

I started Hakufu months ago as a Windows-only app. This autumn I rewrote it from scratch, learning as I went with help from AI, so it runs on any computer and keeps itself up to date.

  1. 0.9
    August 2026

    Windows only, built with WPF. It had accounts and friends in the cloud.

  2. 0.10
    October 2026

    Moved to Avalonia: the same app on Windows, macOS and Linux. No accounts, no servers: your library never leaves your computer.

  3. 0.11
    October 2026

    Updates itself in one click on all three systems, and speaks English and Spanish.

Download

Installs with a double-click and updates itself: when there is a new version, Hakufu lets you know and updates in one click. If you get lost, open the step-by-step guide for your system.

Your system

Windows

Windows 10 or 11, 64-bit.

Download installer

Rather not install? Portable version (.zip), doesn’t update itself.

Open Hakufu-win-Setup.exe: it installs and opens by itself. If Windows warns about an unknown publisher, click More info and then Run anyway.

Your system

macOS

macOS 12 or later.

Apple silicon Intel

Rather not install? Portable version for Apple silicon or Intel, doesn’t update itself.

Open the .pkg and follow the steps: Hakufu ends up in Applications. If macOS won’t open it, go to System Settings → Privacy & Security and click Open Anyway. Only the first time.

Your system

Linux

x64, any recent desktop distro.

Download AppImage

Prefer a folder? Portable version (.tar.gz), doesn’t update itself.

Make it executable (chmod +x Hakufu.AppImage) and open it. If it does not start: sudo apt install libfuse2t64 libfontconfig1 libice6 libsm6.

All versions and release notes on GitHub.

Download the new version and open it: it reads the same data folder, so your collections and progress are still there. Accounts and friends no longer exist; to move your library to another computer, use the .zip backup.

How to install Hakufu

  1. Download the installer. It is saved to your Downloads folder as Hakufu-win-Setup.exe.
  2. Double-click it. It doesn’t ask for administrator rights: it installs for your user and adds shortcuts to the desktop and Start menu.
  3. If you see “Windows protected your PC”, click More info and then Run anyway. It only happens the first time.
  4. Done. Hakufu opens by itself when it finishes. To uninstall it: Settings → Apps → Hakufu.

To update you don’t have to do anything: when there is a new version, Hakufu shows a bar at the bottom. Click Update and then Restart. Your library and progress are not touched.

  1. Pick your version. Apple menu (the apple, top left) → About This Mac: if it says Chip: Apple M1, M2, M3… download Apple silicon; if it says Processor: Intel, download Intel.
  2. Open the installer. In Downloads, double-click Hakufu-osx-…-Setup.pkg.
  3. If macOS says it can’t verify the developer, close the warning, go to System Settings → Privacy & Security, scroll to the bottom and click Open Anyway. Confirm with your password.
  4. Follow the installer’s steps. Hakufu ends up in Applications.
  5. Done. Open it from Applications or Launchpad. Keep it in the Dock if you like.

To update you don’t have to do anything: when there is a new version, Hakufu shows a bar at the bottom. Click Update and then Restart; the security warning doesn’t come back.

  1. Download the AppImage. It is saved as Hakufu.AppImage. Move it wherever you want to keep it (for example, ~/Applications).
  2. Make it executable. Right-click → Properties → Allow executing file as program, or in a terminal: chmod +x Hakufu.AppImage.
  3. Double-click it, or from a terminal: ./Hakufu.AppImage.
  4. If it does not start, install FUSE and the graphics libraries. Ubuntu or Debian: sudo apt install libfuse2t64 libfontconfig1 libice6 libsm6 (on older versions, libfuse2). Fedora: sudo dnf install fuse-libs fontconfig libICE libSM.
