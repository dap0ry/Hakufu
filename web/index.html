Descargar

Descomprime y ábrela. No hace falta instalar nada más.

Windows

Windows 10 u 11, 64 bits.

Descargar .zip

Ábrela con Hakufu.exe. Si Windows avisa de un editor desconocido, pulsa Más información y luego Ejecutar de todas formas.

macOS

macOS 12 o posterior.

Chip Apple Intel

Arrastra Hakufu.app a Aplicaciones. La primera vez, ve a Ajustes del Sistema → Privacidad y seguridad y pulsa Abrir igualmente.

Linux

x64, cualquier distro de escritorio reciente.

Descargar .tar.gz

Descomprime y ejecuta ./Hakufu. Si no arranca: sudo apt install libfontconfig1 libice6 libsm6.

¿Usabas la 0.9 en Windows? Abre la versión nueva: lee la misma carpeta de datos y tu progreso sigue ahí. Todas las versiones en GitHub.
